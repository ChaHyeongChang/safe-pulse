# 시연 영상 촬영 대본 (약 2분 50초)

공모전 시연 영상은 목업·프로토타입·화면 녹화가 모두 인정된다. 아래 순서대로 에뮬레이터 화면을 녹화하고,
자막(또는 내레이션)을 붙이면 된다. 모든 데모는 앱의 **데모 시나리오** 메뉴로 재생되므로 매번 같은 결과가 나온다.

## 준비

1. Pleos Connect Emulator 2.1.0(API 34) AVD 실행 → 앱 설치·실행 → 권한 허용
2. 설정 → 보호자 이름 입력(예: "딸 지은")
3. 녹화: Android Studio 에뮬레이터의 화면 녹화, 또는 OBS로 에뮬레이터 창과 **PC 소리**를 함께 녹화
   (`adb shell screenrecord` 는 소리가 녹음되지 않는다. 음성 코칭이 핵심이므로 OBS 권장)

## 팁

- 데모 1과 6은 보호자 알림까지 보여 주려면 40초 정도 걸린다. 영상에서는 데모 1(응답함)만 쓰고, 보호자 알림은 데모 6을 빨리 감기로 짧게 넣는다.
- 숏폼 챌린지(별도 특별상)에 낼 때는 데모 1의 0:35–1:05 구간을 세로로 잘라 15초 영상으로 만든다.
